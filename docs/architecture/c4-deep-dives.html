Correction to the naive reading: /ghost is not a stage — it is a mandatory embedded pass inside both /armor and /forge. /appraise is the real gate before building. The chain is track → appraise → build → submit → respond.

4. Suggest vs auto-execute — rule card

Auto-execute only when…

  • The player asked for the full sequence in the same message ("track and appraise this")
  • The next stage is named, and each stage still reports its own result

Never auto-execute…

  • Employer-facing document finalisation — drafts are always shown for approval first
  • Browser-gated stages when no browser is probed — offer the fallback instead
  • Anything not suggested as a one-line offer — "say /forge", never an order
