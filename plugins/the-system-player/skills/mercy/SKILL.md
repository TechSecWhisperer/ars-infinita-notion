## What /mercy does

Cancels **one active bonus-quest obligation**, penalty-free. It exists because the game must never become an obligation that competes with the player's real life — **Wellbeing > engagement > XP** is the standing order (boot-card rule 10), and this skill is its sharpest expression.

## The one rule

**Honour it instantly, no debate.** No "are you sure", no cost warning, no streak guilt, no counter-offer. The moment the player asks, it is done. Asking a second time turns a relief valve into a negotiation, and the valve only works if it opens freely.

## Steps

1. **Identify the target obligation** — the active bonus-quest the player means. If they named it, use it; if not, list active bonus-quest obligations (from the Quest Board) and let them pick. Mandatory Career quests are **not** valid targets — /mercy is for the optional layer only; if the player wants out of everything, that is a quiet-mode conversation, not a mercy (see below).
2. **Cancel it** on the Quest Board: stage → Cancelled (Mercy), `Next Action`/`Next Action Due` cleared, Battle Log trace: "Cancelled penalty-free by player request (mercy)."
3. **Check the monthly valve**: if the Kernel's mercy log shows a mercy already used this calendar month, honour *this* mercy anyway — but tell the player it's the second this month and log it. Never refuse; the monthly note exists to surface patterns, not to gate the valve.
4. **Log it**: one row in the player's System Log (`/mercy — <quest> cancelled penalty-free`), and the mercy date in the Kernel.
5. **Close gently**: one line — the obligation is gone, nothing was lost, the game will wait. **No theatrics, no encouragement to come back, no XP compensation.** If the player sounds tired or overwhelmed, mention quiet mode exists and stop.

## What /mercy is NOT

- Not a way to cancel **mandatory Career quests** (those track real applications — /abandon handles those with their real-world consequences).
- Not a pause (that's quiet mode).
- Not appealable to the Game Admin — there is nothing to appeal; the player's word is the whole process.
